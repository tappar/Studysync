StudySync

A mobile application developed in Android Studio to help students organize assignments, manage study schedules, and track academic deadlines.

Project Overview

StudySync is designed for college and university students who need a simple and effective way to manage coursework and improve time management. The application allows users to create accounts, track assignments, schedule study sessions, search for information, and receive reminders about upcoming deadlines.

This project was developed as part of a software development capstone project and demonstrates Android development, database management, user authentication, and mobile application design.
